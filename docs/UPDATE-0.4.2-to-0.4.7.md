# 豆包工作插件 0.4.2 → 0.4.7 更新

这段时间主要修了三件事：流式输出、从客户端读取、额度显示。

## 流式输出

带工具的请求之前是整段缓冲的——要等模型生成完才能解析工具调用，期间客户端一个字都收不到。表现就是「首字 21 秒 = 总耗时 21 秒」，看着像卡住。

现在先收第一个块看首字符：`{` 开头就继续缓冲（是工具调用），其余立刻边收边转发。短问答受益最明显。

顺带修了 `/responses` 路径不解析工具调用的问题（Codex 走那条，之前会把 JSON 原样当正文发出去）。

**有个边界要说清：插件省的是缓冲那几秒，上游生成时间改不了。** 我抓包看到 389ms 收到的是 prompt 回显，真正正文要 8 秒后才到。升级后如果还慢，看 magpie 日志里 `[doubao]` 开头的耗时行，能区分是上游慢还是插件造成的。

## 从客户端读取

这个登录方式之前完全失效，三个 bug 叠在一起：SQLite 内部页的指针读错导致解析出 0 行、profile 路径认不出客户端的 `aha/users/<hash>/profile_explorer` 布局、v10 Cookie 的 host 摘要算错导致值变成垃圾串（而且不报错）。

现在数据目录留空就行，插件会把常见位置都试一遍。

## 额度显示

30 天赠送会标「（赠送）」了，活动赠送卡会单独列一条，上限也不会被百分比吃掉（之前赠送套餐恒返回 `used_percent: 0`，界面上只剩「近 7 天 0」）。

## 其他

- 模型菜单按账号类型走，有订阅 12 个、飞书 9 个，和基线取并集只增不减
- 被风控后不再连打 5 次，冷却也能提前解除
- 上游 400 时会把脱敏后的请求体落盘，能看出是哪部分撑大的
- 支持 Linux（用粘贴 Cookie 登录）
- 非 Windows 的凭据改成真加密，之前是明文
- 客户端断开时主动放掉上游请求，不白花额度

**签到**：Web 签不了，而且试签失败会消耗当天额度（当天作废不可回滚）。插件保持只读，只显示状态，请去电脑版领。
