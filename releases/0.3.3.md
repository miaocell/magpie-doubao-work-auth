- **工具回复被截断时不再作废整轮。** 模型偶尔中途停下，工具调用的 JSON 没闭合（长参数工具较常见），之前会直接报 `invalid_tool_response` 502，这一轮什么都没执行。现在会先尽量救回已经写完的工具调用，救不回来就把正文当普通回复返回（`finish_reason=stop`），让这一轮继续。客户端硬性要求必须调用工具时仍照实报错。
