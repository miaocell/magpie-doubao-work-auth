- **签到改回纯只读。** 领取接口 `POST /alice/ug/campaign/item/reward/claim/` 能调通，但回执固定是 `biz_error.code = 3`「领取结果确认中」，任务状态不变。带全套浏览器上下文直调结果一致，说明卡在客户端侧的校验上，纯 HTTP 绕不过。插件不再发注定失败的写请求（高频失败是风控最敏感的模式），只读状态。
